## F001 — Successive percentage changes
Signed change numbers a and b are percentage points such as +20 and -20.
Net percent change = a + b + (a*b)/100.
Equivalent multiplier: final = initial * (1+a/100) * (1+b/100).
Condition: second percentage applies to the updated value; both changes concern the same quantity. Do not use for different quantities/bases.
Example: 100 → 120 → 96 for +20%, -20%; net -4%.
Equal x% increase and decrease: net decrease x*x/100 percent. This shortcut needs equal magnitudes; ordinary nonnegative price interpretation requires 0<=x<=100.
Trap: +20 and -20 do not cancel because bases differ.

## F002 — Direction and straight-line displacement
Choose east +x; west -x; north +y; south -y.
x = total east - total west; y = total north - total south.
Distance from start = sqrt(x*x+y*y). If one component is zero, distance is absolute value of the other.
Condition: perpendicular straight segments in the stated cardinal directions.
Path length is sum of travelled segments and differs from distance from start.
Example: N4 E3 S4 → x=3, y=0 → 3 km east; path 11 km.
